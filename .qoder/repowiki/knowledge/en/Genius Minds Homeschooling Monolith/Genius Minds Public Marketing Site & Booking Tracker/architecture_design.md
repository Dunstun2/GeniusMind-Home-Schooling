Flat collection of standalone HTML documents at the repository root (index.html, about.html, courses.html, blog.html, blog-post.html, contact.html, faq.html) plus one interactive sub-app under public/track.html. Each page is self-contained: it links the shared stylesheet `styles.css?v=1.x`, Google Fonts (Outfit + Inter), and three client scripts (`analytics.js`, `banner-cta-handler.js`, `script.js`). The navbar and footer are not duplicated per page — placeholder `<div id="navbar-placeholder">` / `<div id="footer-placeholder">` nodes are left empty and filled at runtime by an external partial loader outside this module's scope. SEO is baked in via per-page meta blocks (charset, viewport, description, keywords, robots, canonical URL) plus matching Open Graph and Twitter Card tags, and inline JSON-LD schema blocks (e.g. `EducationalOrganization` on index, `FAQPage` on faq). All images and assets are referenced via absolute URLs rooted at `https://geniusminds.website/`. The only interactive sub-application is `public/track.html`, a dark-themed single-page tracker that reads a `?token=` query parameter, calls `/api/booking/track/{token}` to render booking details and a threaded chat with file attachments via FormData, and auto-refreshes every 15 seconds.
